Edge Basic Auth

登録したドメインへのリクエストに Basic 認証ヘッダーを付ける Edge 拡張機能を生成します。

マスターパスワードを設定

認証情報はマスターパスワードで暗号化して保存します。Edge でも、ブラウザを起動するたびにこのパスワードで解除します。

以前のバージョンで平文保存された登録があります。マスターパスワードを設定すると暗号化して移行し、平文のファイルを削除します。

12 文字以上。1Password などでの生成・保存をおすすめします。忘れると復旧できません。

ロック中

マスターパスワードを入力して解除してください。

登録済みのサイト

まだ登録がありません。「追加」から登録してください。

有効 ラベル ドメイン サブドメイン ユーザー名 パスワード 操作

サイトを追加

ホスト名のみ。URL を貼り付けてもスキーム・ポート・パスは取り除かれます。

サブドメインを含めると、*. のすべてのホストに同じ認証情報が送られます。信頼できるドメインのみで有効にしてください。

空のまま保存すると、現在のパスワードを維持します。

    Edge への読み込み手順

    1. アドレスバーに次の URL を貼り付けて開きます（http のページからはリンクで開けません）。
      edge://extensions
    2. 初回: 「開発者モード」を ON にし、「展開して読み込みます」で上記の出力先フォルダを指定します。ツールバーに拡張機能のアイコンをピン留めしておくと便利です。
    3. 2 回目以降: 設定を保存したら、拡張機能一覧で「Edge Basic Auth (generated)」の「再読み込み」を押します。表示される version が上記と一致すれば反映済みです。
    4. 解除: ブラウザの起動時と再読み込みの後は、拡張機能のアイコンに LOCK が表示されます。アイコンをクリックし、マスターパスワードを貼り付けて Enter で解除します。

    マスターパスワードの変更

    変更後は Edge で拡張機能を再読み込みし、新しいパスワードで解除してください。
